# FlexCityMods PWA

Versão web instalável do FlexCityMods.

## Como usar no iPhone
1. Publique estes arquivos em um serviço de hospedagem que use HTTPS.
2. Abra o endereço no Safari.
3. Toque em Compartilhar.
4. Escolha **Adicionar à Tela de Início**.
5. Abra o ícone FlexCityMods como um app.

A PWA salva favoritos e downloads na memória local do navegador.

## Importante
Esta versão é uma biblioteca/organizador de mods. Ela não instala ou modifica automaticamente os arquivos internos de um jogo iOS.
